Memakai file .cube

CapCut (desktop)

  1. Pilih klip, buka Adjust → LUT.
  2. Klik Import LUT, pilih file .cube.
  3. Atur Intensity sesuai selera.

Concat

  1. Impor .cube sebagai look (masuk kategori Imported).
  2. Taruh look di klip dan atur intensitasnya.

Resolve / Premiere

  1. Kalau sudah pakai CST sendiri, matikan pilihan "termasuk konversi LOG" lalu ekspor ulang.
  2. Pasang LUT setelah node / efek CST.

LUT diterapkan pada footage seperti yang direkam. Kalau aplikasi sudah mengubah LOG ke Rec.709 sendiri, jangan pakai LUT yang sudah termasuk konversi, nanti konversinya jadi dua kali.
